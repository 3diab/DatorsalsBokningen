# DatorsalsBokningen

Startprojekt för **Examinationsuppgift 1** i C#-kursen för Spelutvecklare på Nackademin.

Repositoryt innehåller materialet som behövs för examinationsuppgiften:

- `DatorsalsBokningen.zip` – projektet som ska användas i uppgiften
- `Examinationsuppgift 1.pdf` – instruktioner och krav för examinationen

## Kom igång

1. Ladda ner eller klona repositoryt.
2. Läs igenom `Examinationsuppgift 1.pdf`.
3. Packa upp `DatorsalsBokningen.zip`.
4. Öppna projektet i Visual Studio.
5. Följ instruktionerna i examinationsuppgiften.

## Viktigt

Arbeta i en **egen kopia** av projektet.

Gör dina ändringar lokalt och följ instruktionerna för inlämning i studentportalen.

Ändra inte filerna i detta repository.

## Syfte

Projektet används för att examinera felsökning, felhantering och grundläggande C#-programmering.
